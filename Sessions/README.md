# Sessions

STA1 consists of 12 sessions of two lessons (\(2 \times 45\) minutes). Contact time is short, so each meeting introduces one idea and one engineering example. The corresponding Python tutorial and, later, the assignments carry most of the practice.

The course progression is:

1. describe data;
2. model uncertainty;
3. quantify precision and draw conclusions;
4. compare groups and model relationships; and
5. complete and communicate an integrated analysis.

The normal rhythm of a session is:

| Activity | Time |
| --- | ---: |
| Recap | 10 min |
| The statistical problem and one worked example | 30 min |
| Live Python demonstration | 30 min |
| Start the tutorial or assignment | 20 min |

Before class, read the specified sections and look at the tutorial. After class, finish the tutorial and work on the current assignment.

## How STA1 differs from SMP1

Sessions 02–04 share language with SMP1: events, random variables, and standard distributions. The purpose is different.

- In **STA1** a distribution is a tool for analysing data and making a decision.
- In **SMP1** a distribution is an object whose properties are derived, transformed, and simulated.

Time series, Markov chains, joint distributions, and Monte Carlo modelling belong to SMP1, not to STA1.
